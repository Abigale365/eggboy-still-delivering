## 2. 读代码时额外发现

- Lux3D 文生 3D（G1-Turbo）2026-11-10 实测 **261 s / 344 s**，比 10-31 的约 60 s 慢 4–5 倍。"先保底再替换"变成必须；超时阈值要放到 5–6 分钟。
- 玩家移动不走 Unity 物理：地面是 Ground 层射线（`IslandWorld.GroundAt`），阻挡是自定义圆 / 盒（`EggboyCollider`），可走区域是多边形 + 水位。新造的可踩物体要挂 Ground 层的 BoxCollider，位置还得在可走多边形内。
- `EggboyPlayer.Move(dt, inX, inZ, run, jump)` 是纯输入驱动，残影可以用第二个 `EggboyPlayer` 实例喂录下来的输入 / 位置来得到完整的步态。
