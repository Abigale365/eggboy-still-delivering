# F5–F9 实拍与 EasyInput 快捷键

打开 TideTown.exe，点入游戏窗口后按键。F5–F9 是拍摄辅助，进入后使用独立拍摄存档；退出重开即可恢复原来的正常游玩进度。所有审计模式自动禁用。

| 键 | 到达位置 | 接下来怎么拍 |
|---|---|---|
| F5 | 邮局门前醒来后的演出起点 | 按 S5 / 单按旋钮 / E，播放推门并迈出的动作；适合屏幕、板子、手同框 |
| F6 | 面包店烤炉前，已备好火柴与干柴并点亮炉火 | Tab 重读信；直接对电脑麦克风吹气鼓风，便于拍 H3，不必重解机关 |
| F7 | 学校后门空狗碗前 | V 打开心愿笺，输入“一根香喷喷的骨头”；离线时使用已有模型，不产生付费生成 |
| F8 | 涨潮渡口绞盘前 | R 怀表；C 举木尺取景框，旋钮左右 / A、D 微调，单按旋钮 / S5 / E / 空格拓印 |
| F9 | 当前灯塔顶层，灯已亮，手动信号台已打开 | 直接转旋钮扫海；S5 / 空格闪灯，三次后对岸回应；B 下塔。无需先找油壶、爬塔或解机关 |

F9 使用新版场景真实甲板与灯头位置。拍摄时角色位移锁定，旋钮只转灯。端详或机关弹窗中请先按 Esc 收起，再使用 F5–F9。F5 是现有推门动作演出，邮局门不是新增可开合实体。

EasyInput V2.0 / PCB AI Keyboard V2.1：S1 W、S2 A、S3 S、S4 D、S5 E（互动）、S6 空格、S7 M（地图）、S8 Esc；旋钮左/右对应 A/D，单按对应 E。组合键按现有固件映射：旋钮组合 S4 心愿笺、S5 信件、S6 怀表、S7 下塔、S8 抚摸小黑。机关弹窗中的旋钮用于转当前选中环。

麦克风目前是电脑音频输入。游戏优先物理阵列/USB 麦克风；约 3 秒无有效声波会自动换下一个设备，Virtual/Broadcast 后置。只在旧物端详或已点燃烤炉附近采样，离开即释放。首次使用如系统未授权，请由本人在 Windows 中允许麦克风；也可继续使用 F / 鼠标擦拭和键盘风箱替代。

拍手部视频后放入介绍视频目录的“实拍素材”，文件用 H1～H9 开头（例如 H3_吹气.mp4、H7_灯塔转灯.mp4）。运行“合成实拍手部小窗.ps1”，缺号自动跳过；H1/H7 默认全屏同框，其余左下角圆角小窗。`-WindowOnly` 可让两段也保持小窗。
