## 开发用命令行

| 参数 | 作用 |
|---|---|
| `-lux3d mock\|dev-direct\|relay\|offline` | Lux3D 网关（发布包默认 offline） |
| `-lux3ddelay 秒` | mock 网关的假延迟 |
| `-hints off\|less` | 卡住提示频率 |
| `-nogap` | 渡口木箱全部出现（退回 v3 的自动铺满） |
| `-oldmodes` | 打开 v3 的透视拓印 / 光影声音旧版（2 / 4 键） |
| `-innovaudit` | 创新方向自动审计（`tools\run-audit.ps1 -Mode innov`） |
| `-debugui` | 调试界面 |
